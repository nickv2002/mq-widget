# Privacy Policy for Merge Queue Badge

Last updated: 2026-11-02

Merge Queue Badge is developed by Nick Vance. The extension does not collect any data.

## What the extension stores

The extension stores two settings in your browser:

- The GitHub merge queue URL you enter on the options page. This is saved with Chrome sync, so it may follow your Chrome profile to your other signed-in devices.
- Your GitHub personal access token. This is saved only on the device, in local extension storage, and is not synced.

Neither setting is sent to the developer or to any third party.

## What the extension sends

The extension makes requests only to `https://api.github.com`, to read the number of pull requests in the merge queue you configured. These requests include your token in the Authorization header, as required by the GitHub API. GitHub handles that data under its own privacy policy.

The extension does not contain analytics, advertising, tracking, or crash reporting, and it does not send data anywhere else.

## Data we collect

None. The developer does not receive, store, or have access to any data from this extension.

## Removing your data

Remove the extension from Chrome to delete its stored settings and token. You can also revoke the token at any time from your GitHub settings.

## Changes

If this policy changes, the updated version will be posted in this file and the "Last updated" date will change.
