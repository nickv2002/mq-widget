Merge Queue Badge

Open your repository's merge queue page on GitHub and paste its address: https://github.com/<owner>/<repo>/queue/<branch> Stored only in this browser (not synced) and only sent to api.github.com. It needs read access to pull requests; see below.
How to get a token

Option 1: GitHub CLI (quickest). Run this in a terminal and paste the output above. It already has the right access, including SSO for your organization.

gh auth login   # only if you aren't logged in yet
gh auth token

Option 2: fine-grained token. Create one with the permissions prefilled (read-only Pull requests, Contents and Metadata). On that page:

  1. Under Repository access, choose Only select repositories and pick the repository that owns the queue.
  2. Click Generate token, copy it, and paste it above. If your organization requires approval for tokens, an admin has to approve it before it works.

Option 3: classic token. Create one with the repo scope. If your organization uses SSO, click Configure SSO next to the token and authorize it.

If the count shows but the wait time is missing, the token can't read pull requests. Press Test for details.
